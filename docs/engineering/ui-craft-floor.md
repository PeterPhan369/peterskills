## What it does

Defines the quality floor and anti-pattern defense layer for frontend interface code. When an agent creates or modifies frontend markup, styles, or components, it enforces these standards autonomously without waiting for a manual audit pass.

The defining constraint is that it acts as a passive baseline rather than an interactive questionnaire: it injects production constraints directly into code generation to prevent generic AI templates from entering the codebase in the first place.

## When to reach for it

Type `/ui-craft-floor`, or the agent reaches for it automatically whenever a task touches frontend code, components, or styles.

Reach for this when you want to inspect or understand the baseline visual standards governing agent code output. For targeted audits of existing pages, use [ui-review](https://aihero.dev/skills-ui-review) instead. For active repair and perfection passes, use [ui-polish](https://aihero.dev/skills-ui-polish).

## The craft floor and anti-pattern catalog

The craft floor establishes explicit boundaries across five core dimensions:

* **Contrast and color**: Body copy must meet or exceed 4.5:1 contrast against its rendered surface. Dark interfaces must be tinted with subtle palette undertones rather than raw un-tinted black.
* **Typography**: Line length must stay constrained between 55 and 75 characters per line (`max-w-prose`). Large display headings must use fluid scaling (`clamp()`), multiline titles must balance word wraps, and numeric tables must use tabular figures.
* **Spatial rhythm**: Spacing must scale proportionally: tight grouping for related controls (4px to 8px), moderate margins for field groups (16px to 24px), and generous padding between sections (48px to 80px).
* **Depth and shadows**: Shadows must carry an explicit vertical offset and soft diffusion. Zero-offset chromatic glowing halos and heavy opaque shadows are rejected.
* **Interaction completeness**: Every interactive control must provide distinct hover, active, focus-visible, and disabled states. Focus outlines may never be removed without an accessible replacement.

The skill houses an exhaustive catalog of 59 deterministic detector rules in its reference files, providing concrete definitions and code remediations for recognizable AI tells such as side-tab accent stripes, nested cards, gradient text, and overused typefaces.

## Common questions

**Does the craft floor override my existing design system?**
No. A committed project design system, brand guideline, or explicit brief always takes precedence over the default floor. The craft floor only prevents unguided agents from defaulting to generic AI templates when specific instructions are absent.

**Why does it ban fonts like Inter or Roboto?**
Because models default to them on almost every project, producing interfaces that feel generic and indistinguishable. Choosing an intentional typeface rooted in the product's domain immediately elevates craft and character.

## It's working if

* Frontend components generated by agents avoid purple-blue gradients, side-tab stripes, and nested cards by default.
* Text contrast across light and dark modes passes automated accessibility checks without manual intervention.
* Headings and reading paragraphs remain legible and properly wrapped across mobile viewports.
